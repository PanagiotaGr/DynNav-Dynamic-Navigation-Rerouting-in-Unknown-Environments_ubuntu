# DynNav PhD Application Readiness

## Research maturity

DynNav is an active research platform focused on dynamic navigation, uncertainty-aware planning, risk estimation, and ROS 2/Nav2 integration.

## Current engineering foundations

- ROS 2 navigation stack integration
- Nav2 planner plugin architecture
- Gazebo simulation support
- TurtleBot3 simulation pathway
- Benchmark and reproducibility documentation

## Required future validation

The following areas require additional experimental evidence:

- Real robot hardware validation
- Large-scale benchmark comparison
- Formal safety verification artifacts
- Extended experimental evaluation

## Status

Under active development.
